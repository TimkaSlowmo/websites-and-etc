# Проём — ИИ-расчёт окон и дверей по фото чертежа

<img src="download/icon.png" width="96" align="right">

Приложение для iPhone и Android для сотрудника оконной компании (проект «Батя Макса»).
Фотографируешь чертёж, ИИ читает размеры и параметры, показывает, как будет выглядеть готовое окно, и считает примерную цену по каталогу.

## ⬇️ Скачать

| Телефон | Файл | Как поставить |
|---|---|---|
| 🤖 Android | **[Proyom.apk](https://github.com/TimkaSlowmo/websites-and-etc/raw/main/batya-maksa/Proyom.apk)** | Открыть ссылку на телефоне → скачать → открыть файл → «Установить». Если Android спросит, разрешить установку из браузера. |
| 🍎 iPhone | **[Proyom.ipa](https://github.com/TimkaSlowmo/websites-and-etc/raw/main/batya-maksa/Proyom.ipa)** | Через Sideloadly, см. ниже. |

Или в репозитории: папка `batya-maksa` → файл → кнопка ⬇︎ справа. Файлы обновляются сами после каждого изменения кода.
Новая версия ставится поверх старой, история и настройки сохраняются.

## 📲 Установка на iPhone

1. Скачай `Proyom.ipa` на Mac или ПК.
2. Открой [Sideloadly](https://sideloadly.io), подключи iPhone кабелем.
3. Перетащи `Proyom.ipa` в Sideloadly, введи свой Apple ID, нажми **Start**.
4. На iPhone: **Настройки → Основные → VPN и управление устройством → твой Apple ID → Доверять**.
   Если iOS попросит, включи **Режим разработчика**.

С бесплатным Apple ID приложение работает 7 дней. Потом поставь так же поверх.

## Как пользоваться

| Вкладка | Что делает |
|---|---|
| **Расчёт** | «Снять чертёж» или «Выбрать из галереи». ИИ заполнит размеры, вид окна, створки, профиль, стекло, допы. Всё можно поправить вручную, цена пересчитывается сразу. Переключатель «Чертёж / Готовый вид» показывает фото окна, нарисованное ИИ. Внизу: КП в PDF, отправка расчёта, сохранение в историю. |
| **История** | Все сохранённые расчёты. Нажми, чтобы открыть, свайп влево — удалить. |
| **Каталог** | Текущие цены: профили, стеклопакеты, фурнитура, цвета, допы, монтаж. |
| **Настройки** | Название компании для КП, загрузка своего каталога (JSON). |

ИИ уже подключён и работает сразу, ничего настраивать не нужно.
ИИ читает чертёж двумя моделями одновременно и сверяет цифры. Если они разошлись, под размерами появятся кнопки
с другим вариантом («Ширина 1300») — сверь с чертежом и нажми нужную. При низкой уверенности появится предупреждение.

## Каталог и цены

Цены в приложении пока **примерные**. Свой каталог загружается во вкладке «Настройки» файлом JSON
в формате [`ios/OknoCalc/Resources/catalog.json`](ios/OknoCalc/Resources/catalog.json).

Как считается цена: профиль и стеклопакет по м² → фурнитура по каждой створке → наценка за цвет →
подоконник, отлив, откосы, сетка → монтаж → наценка компании → НДС → округление до 100 ₸.

## Что внутри

- `ios/` — приложение для iPhone (Swift / SwiftUI, iOS 17+).
- `android/` — приложение для Android (Kotlin / Jetpack Compose, Android 9+). Каждая сборка проверяется на эмуляторе.
- `worker/` — ИИ-сервер на Cloudflare Workers AI: читает чертёж (Llama 4 Scout и Mistral Small параллельно, со сверкой) и рисует готовое окно (FLUX).
- `download/` — страница скачивания: https://timkaslowmo.github.io/websites-and-etc/proyom/

Всё собирается и выкладывается автоматически через GitHub Actions после каждого изменения,
Mac и Xcode не нужны. Бесплатного лимита ИИ хватает примерно на 70–100 расчётов в день (обнуляется в 05:00 по Алматы).
