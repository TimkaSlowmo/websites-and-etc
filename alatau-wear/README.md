# ALATAU Wear

Демо-магазин одежды для портфолио: каталог, фильтры, карточка товара, корзина, промокод `WELCOME10`, заказ в WhatsApp.
Один файл `index.html`, без сборки: открыть в браузере или `npx serve .`

Настройки магазина (название, WhatsApp, доставка, промокоды) — блок `SHOP` вверху скрипта; товары — массив `PRODUCTS`.
Товары, цены и контакты вымышленные. Админки нет.
