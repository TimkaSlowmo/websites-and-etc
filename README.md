| Папка | Что это |
|---|---|
| `zhanar-cosma/` | Сайт студии перманентного макияжа Zhanar Cosma (Алматы). Собранная версия из bolt.new, исходников пока нет |

## Правила

- В каждой папке свой `README.md` с описанием и способом запуска.
